# Exit codes

| Code | Meaning |
|---:|---|
| 10 | Invalid or direct invocation |
| 11 | Log initialization failure |
| 12 | Marathon, Steam App ID, or process-privilege validation failure |
| 13 | Another SteamFix instance or existing Marathon session |
| 14 | Steam installation or renderer DLL discovery failure |
| 15 | Overlay renderer already loaded into steamfix.exe |
| 16 | Renderer permission protection or recovery failure |
| 17 | Marathon launcher process creation failure |
| 19 | Unexpected internal failure |
